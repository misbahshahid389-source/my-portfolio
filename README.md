Azure Static Portfolio Website
Project Overview
This project is a static portfolio website deployed using Microsoft Azure Storage Static Website Hosting. The website is built with HTML and CSS and hosted online through an Azure Storage Account.
Tools and Technologies Used
HTML
CSS
Microsoft Azure
Azure Storage Account
Static Website Hosting
GitHub
Project Files
File / Folder Name	Format	Purpose
index.html	HTML File	Main webpage of the portfolio website
style.css	CSS File	Styling and design of the website
README.md	Markdown File	Project documentation for GitHub
screenshots/	Folder	Contains screenshots and evidence of project steps
report/project-report.pdf	PDF File	Final report file for submission
Deployment Steps
Created a project folder for the portfolio website.
Created index.html for the website structure.
Created style.css for website design and styling.
Created an Azure Storage Account.
Enabled Static Website Hosting in Azure.
Uploaded index.html and style.css into the $web container.
Copied the Azure Primary Endpoint URL.
Tested the live website in the browser.
Created a GitHub repository and uploaded project files.

This project demonstrates how to host a static website using Microsoft Azure Storage Static Website Hosting. It covers cloud storage configuration, static site deployment, and project documentation using GitHub.
