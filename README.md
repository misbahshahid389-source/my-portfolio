# Azure Static Portfolio Website

## Project Overview
This project is a static portfolio website deployed using Microsoft Azure Storage Static Website Hosting. The website is created using HTML and CSS and hosted online through Azure Storage Account.

## Tools and Technologies Used
- HTML
- CSS
- Microsoft Azure
- Azure Storage Account
- Static Website Hosting
- GitHub

## Project Files

| File / Folder Name | Format | Purpose |
|---|---|---|
| index.html | HTML File | Main webpage of the portfolio website |
| style.css | CSS File | Styling and design of the website |
| README.md | Markdown File | Project documentation for GitHub |
| screenshots/ | Folder | Contains screenshots and evidence of project steps |
| report/project-report.pdf | PDF File | Final report file for submission |

## Deployment Steps
1. Created a project folder for the portfolio website.
2. Created index.html for the website structure.
3. Created style.css for website design and styling.
4. Created an Azure Storage Account.
5. Enabled Static Website Hosting in Azure.
6. Uploaded index.html and style.css into the $web container.
7. Copied the Azure Primary Endpoint URL.
8. Tested the live website in the browser.
9. Created a GitHub repository and uploaded project files.
